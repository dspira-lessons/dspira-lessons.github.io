# DSPIRA Lessons

This is a website that provides instructions for designing and using a horn telescope. This project is called Digital Signal Processing in Radio Astronomy (DSPIRA). Visit it at https://dspira-lessons.github.io

This project a fork of the original repository to remove the vibecoded redesign. This project may be refactored and updated according to maintainer availability. Otherwise, it works well as it is.
